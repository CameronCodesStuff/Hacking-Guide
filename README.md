<h2 id="distro">Distro</h2>

### Linux Distros for Hacking

Linux has loads of distros suited to cybersecurity, penetration testing, privacy, development, and everyday use. Here are a few popular ones:

<details>
<summary>ParrotOS — My Choice</summary>

**What it is:**
ParrotOS is a Debian-based Linux distro designed for security, privacy, development, and everyday computing.

**Pros:**

* Lots of hacking and security tools included
* Lightweight and runs well on older hardware
* Privacy-focused features
* Good for both cybersecurity and normal daily use
* Debian-based, with plenty of software and documentation

**Cons:**

* Can take some time to learn if you're new to Linux
* Some security tools require extra configuration
* Its security-focused setup may be unnecessary for basic users

**Why I use it:**

> I use **ParrotOS** because it gives me a solid set of hacking tools while still being comfortable and practical for **daily usability**.

</details>

<details>
<summary>Kali Linux</summary>

**What it is:**
Kali is a Debian-based distro built specifically for penetration testing and security research.

**Pros:**

* Huge collection of security tools
* Excellent cybersecurity documentation
* Great for labs, CTFs, and penetration-testing practice
* Widely used in cybersecurity

**Cons:**

* Not designed primarily as a normal everyday desktop
* Beginners may find some tools and configurations confusing
* Can be more resource-heavy depending on the desktop setup

</details>

<details>
<summary>BlackArch</summary>

**What it is:**
BlackArch is an Arch Linux-based distro focused heavily on penetration testing and security research.

**Pros:**

* Massive collection of security tools
* Highly customizable
* Great for experienced Linux users
* Arch ecosystem gives you plenty of control

**Cons:**

* Steeper learning curve
* Requires more hands-on configuration
* Better suited to experienced Linux users than complete beginners

</details>

<details>
<summary>Ubuntu</summary>

**What it is:**
Ubuntu is a general-purpose Linux distro rather than a dedicated hacking distro.

**Pros:**

* Beginner-friendly
* Huge software ecosystem
* Loads of documentation and community support
* Excellent for everyday computing
* Security tools can be installed when needed

**Cons:**

* Does not come with a large hacking toolkit by default
* You will need to install and configure security tools yourself
* Less security-focused out of the box than ParrotOS or Kali

</details>

## Quick Take
